# 《硅之路》（暂名）

1960 年，电脑有一间房那么大，你的公司却只有一间房那么小。

你将经营一家横跨七十年的科技公司，从一副不断变化的时代牌组中抽取订单、发明、事故、商业骗局和偶尔真正有用的人才。每张卡都是一次决策，每次选择都会直接改变公司的资金、技术、人才与市场。

天才工程师可能带来划时代的设计，也可能开口就要公司股份；大客户可能让你一夜暴富，也可能在二十年后提醒你，当年的合同没有写终止日期。那些看起来毫无用处的古怪项目，则可能在人工智能时代突然变得更加古怪。

三次行业危机将决定公司能否继续存在。失败后，你可以回到过去的时间节点重新选择，但某些决定的影响会横跨数十年。你可能建立科技帝国、成为行业背后的隐形巨头，也可能因为把全部资金投入电子宠物而提前结束职业生涯。

> 看懂未来并不重要。重要的是在未来到来之前，你的账户里还有钱。
