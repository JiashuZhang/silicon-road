# 《硅之路》时代反馈界面（概念稿）

> **文档状态（2026-09）**：报纸、终端、网页等反馈媒介和单卡交互规范继续有效；逐年四张牌流程属于旧原型。机会选择、关键经营周期与时长以 [《硅之路》15 分钟 Build 垂直切片](15-minute-build-slice.md) 为准。

## 一、核心概念

玩家完成一张卡牌的选择后，不立刻进入下一张牌，而是先通过当时年代的主流信息媒介看到选择造成的剧情结果。

反馈媒介会随着游戏年代逐步演变：早期是报纸，后来变成电脑屏幕，最终变成手机。它只改变剧情反馈的视觉表现，不改变抽卡规则、数值规则或结局判定。

这套变化需要让玩家直观感受到七十年正在流逝，同时避免为每个年代制作一套完全不同的游戏界面。

## 二、基础流程

1. 周期开始时，以时代新闻公布环境变化、危机距离和本期机会。
2. 玩家从四个机会中选择两个，并决定处理顺序。
3. 当前事项以等待签署的纸质文件落在公司桌面上，选择位于文件左右或下方。
4. 卡面直接显示受影响属性的方向；玩家点击签章，或把文件拖向左侧或右侧完成决定。
5. 文件影像飞出桌面，结果以报纸、终端或网页剪报落回同一桌面。
6. 若形成能力协同，结果页追加一次独立的协同揭晓；否则直接处理下一项议程。
7. 两项议程结束后展示周期报告，再进入下一个关键年份。

长期影响不在此处完全公开。界面只展示已经发生的事情，以及玩家当前能够知道的结果。

## 三、媒介演变

### 1960—1979：报纸

选择结果以报纸头版、商业小报或行业简报的形式出现。

报纸标题负责总结事件，短文补充结果，页面角落揭晓具体数值变化。例如：

- 资金 `-10`
- 技术 `+15`
- 人才 `+5`

一些规模很小或十分丢脸的事件不会登上头版，而会出现在分类广告、招聘栏或报纸角落。

### 1980—1999：电脑

反馈逐渐切换到办公室电脑。早期可以表现为单色终端和简陋新闻数据库，随后过渡到图形化桌面、电子邮件和网页。

同一套反馈结构可以更换外壳：

- 公司内部备忘录
- 新闻数据库
- 电子邮件
- 早期门户网站

系统偶尔可以用弹窗、连接失败或低俗网页广告制造时代笑点，但不能影响信息阅读。

### 2000—2014：笔记本电脑

剧情结果主要通过新闻网站、邮件、论坛和社交平台显示。界面比早期电脑更紧凑，也开始同时出现公众评价与公司内部消息。

重大事件可以成为新闻首页；人才离职或项目延期则更适合通过邮件和论坛帖子表现。

### 2015—2030：手机

反馈转移到手机，通过新闻推送、聊天消息、短视频标题和社交平台热榜呈现。

信息传播速度更快，语气也更情绪化。同一次产品事故可能连续产生数条推送，但应合并在一个反馈界面中，避免玩家重复点击。

数值变化始终固定显示在清晰区域，不能藏在模拟社交内容里。

## 四、统一信息结构

无论媒介如何变化，每次反馈都保持相同的信息层级：

- **结果标题**：一句话说明发生了什么。
- **剧情短文**：用一至三句话解释后果。
- **数值结算**：明确显示每项实际变化。
- **长期提示**：必要时只显示“这项决定可能产生长期影响”，不公开触发条件。
- **继续操作**：关闭当前反馈并进入下一张牌。

统一结构能减少开发量，也能防止后期手机界面和早期报纸变成两套不同的玩法。

## 五、危机与结局

三次危机应使用对应时代媒介的特殊版本：

- 报纸连续刊登倒闭、裁员和价格战新闻。
- 电脑不断收到订单取消与内部告急邮件。
- 手机被供应中断、股价下跌和公众质疑的推送占满。

中途失败时，媒介展示公司的最后一条消息，再进入失败原因和时间回溯界面。

最终结局可以快速回放不同时代的媒介画面，让玩家看到公司如何从一则不起眼的报纸消息走到 2030 年的最终报道。

## 六、制作约束

为控制两人团队的工作量：

- 决策界面始终使用桌面和文件隐喻，只替换文件类别与选择签章。
- 使用一套固定布局和数据字段，不为每种媒介开发独立逻辑。
- 每个大时代只制作一套主要视觉皮肤。
- 报纸、电脑和手机共享标题、正文、数值变化与继续按钮。
- 每种文件媒介只显示一个印章，标题区必须为印章预留独立空间，不得与标题重叠。
- 手机端把选择签章移到文件下方，避免正文与选择互相遮挡。
- 桌面端普通结果应在常见显示器高度内完整显示正文、结算和继续按钮；只有内容确实超长时才允许纵向滚动。
- 结果媒介支持向左滑动或拖动进入下一页，向右拖动只回弹；左方向键提供等价操作。
- 动画以换页、开机、窗口弹出和推送出现为主，不制作复杂角色演出。
- 优先保证文字清晰和反馈速度，时代装饰不能拖慢连续抽卡节奏。
- 点击按钮始终作为键盘和触屏兜底；拖动动画不得控制业务状态。
- 手机端把左右签章移到文件下方，避免正文与选择互相遮挡。

## 七、预期作用

这套界面演变不增加剧本分支，却能持续提醒玩家时间正在前进。相同的选择结果经过不同媒介呈现，也会自然产生时代感和黑色幽默：

1960 年，公司事故可能要等到第二天才登报；2030 年，产品还没有冒烟，手机已经询问玩家是否愿意公开道歉。
