# Robot Test MVP

这是当前 7 回合灰盒的无界面 Node.js 模拟器。它直接读取根目录的 `cards.config.js`，批量运行 8 种玩家人格，并报告 Build 爆发率、幸存率、倒闭率及估算真人游戏时长。

## 运行

需要 Node.js 18 或更新版本，无需安装依赖。

```powershell
node robot-test/run.js --runs 10000
node robot-test/run.js --runs 10000 --personality tech --seed 100000
```

默认运行 `tech`（技术专精）、`customer`（客户专精）、`manufacturing`（制造专精）、`profit`（短期逐利）、`cautious`（风险厌恶）、`hybrid`（混合构筑）、`beginner`（新手）和 `random`（纯随机），每种 1000 局。

`experienced`（熟练玩家）作为额外基准保留，可单独运行。旧的 `--strategy` 参数仍兼容。

## 人格架构

所有人格共用 `simulator.js` 中的特征评分器。`personalities.js` 只配置路线偏好，以及路线匹配、缺失核心、行动时机、即时收益、生存风险、混合能力和随机扰动等权重。新增人格不需要复制游戏规则或重写机器人。

人格代表待验证的行为假设，不是真人结论。取得真人日志后，应根据实际选择分布校准权重和各人格占比。

## 时长模型

时长不是 Node.js 执行耗时乘固定系数，而是每回合的阅读、比较、点击、结果观看、能力替换和危机思考之和。默认参数在 `simulator.js` 的 `DEFAULT_TIME_PROFILE` 中：

- 阅读速度：每秒 5 个字符；
- 机会选择思考：5 秒；
- 二选一思考：8 秒；
- 点击：0.8 秒；
- 结算观看：3 秒；
- 危机思考：10 秒。

每项耗时加入固定种子的轻微波动。同一种人格和种子会得到相同结果。获得真人测试数据后，应使用首局与重开局的中位数据分别校准这些参数。

决策页默认折叠的背景故事不计入基础阅读时间；玩家主动展开时产生的额外阅读暂未模拟。

## MVP 限制

- 人格机器人是启发式策略，不代表最优玩家或真实玩家比例。
- 机器人仍按旧版“三选一再二选一”流程选牌；Web 版已改为每回合直接发一张二选一卡，因此当前胜率和时长不能作为新版交互基准。
- 当前只评估现有 6 个经营回合加最终危机，不模拟文档中的未来 12 回合版本。
- 本版本只提出统计结果，不会自动改写卡牌数值。
